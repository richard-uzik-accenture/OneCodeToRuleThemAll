## Fix mobile view
When I open the app on my iPhone 15 Pro Max it's not doing a good job presenting the app — the webapp is zoomed and not fitting to screen automatically. Prepare a forensic review of the state of mobile adoption and responsiveness.

## Add edit option
If I mistype on a task I need to remove it and create a new one, going through the whole flow again. I would like a simple pencil icon that allows me to edit an existing task.

## Add tags to tasks
I would like tasks to have a tags field allowing me to put one or more tags (e.g. if it's a work task I can tag a client, or if it's personal I can tag it like — school, finance, etc.).

## Add PWA notification flow
When I open the website on my phone I should be informed and directly asked by the browser to install the app as a PWA to the home screen. Research the possibility of visualizing such a popup with install instructions.

## Add optional due time for tasks
In case I need to remember a due time, I want to be able to add this field. Ideally not during the morning flow or leftover flow, but only on the today view screen via edit.
